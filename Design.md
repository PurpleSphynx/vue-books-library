# Design.md

## Направление

Упрощённый editorial-интерфейс: тёплый фон бумаги, тёмный текст, один терракотовый акцент и выразительные обложки. Основной сценарий проектируется сначала для узкого экрана.

## Базовые правила

- Фон: `#f7f4ee`, поверхности: `#fffdf8`, текст: `#25231f`, акцент: `#c4553d`.
- Шрифт интерфейса: системный sans-serif; крупные заголовки — Georgia.
- Базовый отступ: 4px; карточки имеют мягкую границу и скругление 16px.
- Кнопки и поля имеют минимум 44px высоты для touch-взаимодействия.
- На мобильном каталоге одна колонка, с `md` — сетка; фильтры раскрываются на мобильном.
