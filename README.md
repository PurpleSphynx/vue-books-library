# Лист — каталог книг

Vue 3 + TypeScript + Vite + Bootstrap 5 + Pinia. Реализованы публичный каталог, авторы, отчёт, JWT-вход и CRUD.

## Запуск

```bash
npm install
npm run dev
```

## Переключение между mock и реальным API

Скопируйте `.env.example` в `.env`. Настройте переменные окружения:

| Переменная | Описание | По умолчанию |
|---|---|---|
| `VITE_USE_MOCK` | `true` — локальные mock-данные, `false` — реальный API | `true` |
| `VITE_API_URL` | Базовый URL API (например, `/api/v1`) | `/api/v1` |

**Пример `.env` для mock-режима:**
```
VITE_USE_MOCK=true
VITE_API_URL=/api/v1
```

**Пример `.env` для реального API:**
```
VITE_USE_MOCK=false
VITE_API_URL=https://api.example.com/api/v1
```

Демо-вход: `reader` / `booklover`.

## Функционал

### Гость (просмотр)
- Просмотр каталога книг с фильтрацией (по названию, автору, году)
- Просмотр детальной информации о книге
- Просмотр списка авторов
- Просмотр информации об авторе и его книгах
- Просмотр отчёта ТОП-10 авторов по количеству книг за год
- Подписка на нового автора (UI-заглушка)

### Пользователь (CRUD, после входа)
- Создание, редактирование, удаление книг
- Создание, редактирование, удаление авторов
- Загрузка обложки книги
- Привязка нескольких авторов к книге

### Технические особенности
- **Mobile-first** адаптивный дизайн
- **JWT авторизация** с проверкой срока действия токена (7 дней)
- **TypeScript strict mode** — полная типизация всех сущностей
- **Lazy loading** всех страниц для оптимальной загрузки
- **Кастомная тема** на основе Bootstrap 5 с editorial-стилем
- **Модальные окна** для уведомлений
- **Пагинация** результатов поиска

## Структура проекта

```
src/
├── app/           # App shell, router, глобальные стили
├── pages/         # Страницы (каталог, книга, авторы, отчёт, вход)
├── shared/        # Общий код
│   ├── api/       # API-клиент и методы
│   ├── composables/ # Бизнес-логика
│   ├── mock/      # Mock-данные
│   ├── stores/    # Pinia store (auth)
│   ├── types/     # TypeScript-типы
│   └── ui/        # Переиспользуемые компоненты
└── widgets/       # Виджеты (шапка приложения)
```
